# CoursesApp

Краткое описание структуры модулей проекта:

## Архитектура
Проект построен с использованием многомодульной архитектуры, разделенной по слоям и фичам.

### Основные модули
- **:app** — точка входа в приложение, конфигурация Hilt и инициализация.
- **:domain** — чистая бизнес-логика: сущности (entities) и сценарии использования (use cases). Не зависит от Android.
- **:data** — реализация репозиториев, работа с сетью и источниками данных.

### Слой Core (Общие компоненты)
- **:core:ui** — общие UI-компоненты, кастомные View, ресурсы (цвета, стили) и базовые классы для адаптеров.
- **:core:navigation** — логика навигации между модулями.
- **:core:common** — утилиты, расширения и общие хелперы.
- **:core:database** — локальное хранилище данных.

### Слой Feature (Функциональные модули)
- **:feature:auth** — авторизация и регистрация пользователей.
- **:feature:home** — главный экран со списком курсов и поиском.
- **:feature:favourites** — экран избранных курсов.
- **:feature:account** — профиль пользователя и настройки.

## Технологии
- **Kotlin** + **Coroutines**
- **Clean Architecture**
- **MVVM**
- **Hilt** (Dependency Injection)
- **Navigation Component**
- **Retrofit** (Network)
- **Coil** (Image loading)
- **AdapterDelegates** (Complex lists)

## Сборка
- В папке **apk** хранятся скомпилированные APK файлы.
